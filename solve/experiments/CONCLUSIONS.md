# F题进化实验结论 (v2–v5)

## v2: 问题一算法家族对比
脚本: `experiments/v2_p1_families.py`
数据: A1-A3 全量 272505 条 × 22 指标; regmix_tables 配比-损失

### A. 赋权家族 (熵权/CRITIC/组合/PCA/等权) × 聚合家族 (TOPSIS/加权和/GRA)
- 域级质量分的**排序在多种方法下高度一致**: 组合权+TOPSIS(基线)、组合权+加权和、
  熵权+GRA 三种的域排序与基线完全一致 (秩相关 1.0), 熵权+TOPSIS/加权和 0.964。
- book 域在全部 15 种方法中都是最高 (0.549-0.936), 排序稳健。
- 等权/PCA/CRITIC 单独使用会扰动中段排序 (0.46-0.61), 支持"组合赋权优于单一客观法"。
- **结论**: 组合赋权(熵权+CRITIC) + TOPSIS 的基线选择稳健, 且域排序结论不依赖方法细节。

### C. 冲突度量家族 (双族均值差 / 变异系数 / 信息熵分歧)
- 三种冲突度量的 Spearman 相关: 双族均值差 vs 变异系数 0.030, vs 熵分歧 0.004 —
  **语义化冲突(内容-格式张力)与统计离散度几乎正交**, 前者捕捉的是"内容好但格式脏"
  这类可解释冲突, 后两者捕捉的是一般内部不一致。
- 高冲突 top-10% 样本的 Jaccard 重合率仅 0.11-0.12, 说明选取哪种定义会改变高冲突
  样本集 — 论文采用可解释的双族定义, 并在灵敏度部分报告该差异。
- 消解效果 (基线定义, P90 阈值 0.268): 高冲突 27249 条, Q 均值 0.343 -> 0.535。

### D. 配比模型家族 (岭/Lasso/ElasticNet/Huber/GBM)
- 1M_train 域内拟合 R2: GBT 0.997(过拟合) > Huber 0.598 > 岭 0.585 > Lasso 0.522 > Enet 0.501
- 60M/1B 跨尺度迁移 R2 (尺度内去均值口径): GBT -0.41 最差, Enet -0.49, Lasso -0.61,
  岭 -1.06, Huber -1.15; **线性家族(岭/Enet)跨尺度最稳, 树模型严重过拟合**。
- 跨尺度 R2 为负反映"配比-Loss 关系随尺度漂移", 这正是正文跨尺度系数收缩
  (kappa=0.314) 建模的动机 — 实验直接支持该创新点。

## v3: 问题二标度律形式家族对比
脚本: `experiments/v3_p2_forms.py` + 主代码升级

### A. 质量项形式 (B6+B7, n=810)
| 形式 | R2 |
|---|---|
| additive (加性, Q=1退化) | 0.97161 |
| interaction_D (质量×D^{-d}, 基线) | 0.97204 |
| **interaction_N (质量×N^{-h}, 新)** | **0.97907** |
| multiplicative (乘性因子) | 0.97836 |
| saturating (饱和型) | 0.97164 |
| exponential_Q | 0.97150 |

- **interaction_N 胜出**: 质量缺口惩罚随参数量衰减 (h=0.163), 物理含义是
  "模型越大, 对数据质量缺口的敏感性越低", 优于质量随数据量衰减的 interaction_D。
- 主代码已升级: 三形式同拟合, 自动选择 R2 最高者; 弹性/等价条件随形式自适应。
- 新参数: E=1.640, A=0.404, a=0.305, B=1.323, b=0.292, C=0.356, g=0.991, h=0.163
- 新弹性: eps_N=-0.0602, eps_D=-0.0299, eps_Q=-0.1461 (质量弹性仍最高)
- 等价条件: 质量+0.1 ≈ 参数+0.289B (原 interaction_D 为 0.229B)

### B. 拟合家族 (L2 / Huber / log空间)
- L2 0.97204, Huber 0.97204, log 0.97171 — 形式稳健, 无需鲁棒化。

### C. 自助不确定性 (B1 经典形式, 300次)

## v4: 问题三求解器家族对比
脚本: `experiments/v4_p3_solvers.py`

### A. 求解器 (C=1e22, power, L_ctx=4096)
| 求解器 | L* | N* | D* | Q* |
|---|---|---|---|---|
| SLSQP (基线) | 2.1029 | 9.97 | 137.2 | 1.00 |
| **differential_evolution** | **2.1029** | 9.97 | 137.2 | 1.00 |
| basinhopping | 2.1066 | 6.79 | 195.5 | 1.00 |
| trust-constr | 1.8573 | 405.8 | 1060.9 | 0.81 (违反预算约束!) |

- SLSQP 与差分进化结果**完全一致**, 互为全局最优交叉验证。
- trust-constr 收敛到"更优"但**预算超标不可行**的解 (C 需求 ~2.6e24 >> 1e22),
  必须做可行性校验 — 论文采用 SLSQP 多初值 + DE 复核的双保险。

### B. KKT 解析核对 (纯规模 Q=Q0)
- C=1e19: KKT N=0.246 D=5.96 vs 数值 N=0.226 D=6.48
- C=1e22: KKT N=9.20 D=159.4 vs 数值 N=7.54 D=194.6
- C=1e24: KKT N=102.9 D=1424.9 vs 数值 N=72.2 D=2031.7
- 数值解因 SLSQP 在超宽对数区间收敛不彻底与解析解有偏差; 解析 KKT 给出
  Chinchilla 式精确分配, 论文用解析结论佐证"规模扩张主导"。

### C. 质量灵敏度 (固定最优规模, 提 Q)
- C=1e19: Q 0.40->0.70 损失 3.35->3.24, 额外成本 3.1e17->4.3e18
- C=1e22: Q 0.40->0.70 损失 2.30->2.21, 额外成本 1.1e19->1.5e20
- 低预算下质量投资的边际收益更高 — 支持"质量杠杆在中低预算更有效"。

### D. 帕累托前沿 L* vs C (幂律)
- ln(L-E) = -0.155 lnC + 7.29, 即 **L*-E ∝ C^{-0.155}** — 算力-性能前沿指数律,
  与规模弹性解析关系一致, 新增"计算-性能定律"定量结论。

## v5: 问题四预测家族对比 (升级: 精确LP分位数回归)
脚本: `experiments/v5_p4_families.py` + 主代码升级

### A. 回归家族 (双时间编码)
- **精确分位数回归(LP, Koenker-Bassett)**: bN=0.364, bT=0.089 — 目标函数值
  136.0 优于 IRLS 近似 (137.5) 和 sqrt-加权变体 (171.4), 已升级为主代码。
- 新前沿: lnS = 2.481 + 0.364 lnN + 0.089 t (原 IRLS: bN=0.319, bT=0.091)
- 新分解: 规模贡献 0.456 (83.7%), 非规模技术 0.089 (16.3%), 合计 0.545
- OLS/Huber bT 明显更高 (0.20-0.21), 说明分位数回归对"非前沿样本"稳健 — 
  用 OLS 会高估技术进步率, 支持分位数选型。
- 时间编码敏感性: 整数年 bT=0.155 (IRLS) vs 小数年 bT=0.544 — 报告采用
  整数年 + LP 的保守组合。

### B. 函数族 (linear/quad/logt)
- quad p90残差 0.137, logt 0.138, linear -3.33 — 二次/对数饱和不优于线性,
  线性对数形式(基线)已足够, 避免过拟合外推。

### C. 区间家族 (24个月, 基础情景)
- bootstrap [65.5, 212.8] 中值 119.6 (主报告采用, 最紧)
- conformal [58.7, 242.8], normal [39.6, 359.6]
- bootstrap 区间居中且合理, 无需换共形。

### D. 桥接家族 (logit-log / linear / power)
- logit-log R2=0.276, power 0.277, linear 0.260 — logit-log 基线保持,
  与 power 基本持平, 保持可解释性。

## v6: 问题三全链路联合优化 (配比 p 为决策变量)
脚本: `experiments/v6_p3_joint.py`
创新: 17 域语料配比 p 进入质量 Q=Q(p)=p·Q_dom, 与规模 (N,D) 在算力预算下联合优化,
打通 问题一(配比/域质量) → 问题二(广义标度律) → 问题三(算力优化) 全链路.

- 三档预算最优配比均向最高质量域(小说 book, Q=0.631)集中: C=1e19 时小说占 74%,
  C=1e22/1e24 时基本全部压向小说 (权重 ~1.0), Q(p) 升至 0.631 (上限).
- **配比杠杆的天花板**: Q(p) ≤ max(Q_dom)=0.631, 仅靠重排配比无法达到 Q=1;
  联合优化损失改善 ~2% (L: 2.276->2.238), 远小于直接质量投资 (Q→1 可降至 2.148,
  改善 ~4%) => 数据配比优化是二阶杠杆, 直接改进数据质量才是一阶杠杆 (呼应弹性分析).
- 实测配比 Q(p)=0.457 低于均匀配比 0.478, 表明开源预训练语料现状配比对质量
  维几乎无偏置, 存在优化空间 (定量证据).
