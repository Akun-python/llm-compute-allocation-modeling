\begin{abstract}

算力约束下的模型资源配置问题是一种多维度联合优化问题。本文针对``如何
配置数据、参数与训练规模以最大化大语言模型能力''这一问题，通过数据质量
度量、广义标度律、算力约束联合优化与前沿预测四个递进环节，建立了
``质量评分--冲突消解--配比建模--广义标度律--联合优化--前沿分解预测''
的完整模型链，采用组合赋权、对称截尾融合、岭回归、多起点序列二次规划与
分位数回归等方法，对资源配置决策进行研究；全部数值结果由真实附件数据
计算得到，可由随附脚本在附录 B 数据口径下复算。

\textbf{针对问题一：构建数据质量评分与配比效应模型。}首先，对 22 项质量
指标（14 项标量、8 项列表型）经方向统一、1\%/99\% 缩尾与 Min--Max
归一化后，采用熵权与 CRITIC 组合赋权（0.5:0.5）并叠加 TOPSIS 贴近度，
建立样本级质量分 $Q$。随后，定义``内容质量族''与``格式清洁族''两族指标
均值之差的绝对值作为冲突指数，对高冲突样本（第 90 分位阈值 0.268）实施
对称截尾融合消解，得到七域域级质量：book 0.631、arxiv 0.486、c4 0.429、
commoncrawl 0.408、github 0.386、wikipedia 0.365、stackexchange 0.339，
抽样集与全量集质量高度一致（arxiv 0.481 vs 0.486），验证了评分的可迁移性。
最后，对 13 个损失域、17 维配比建立岭回归配比模型，并提出``跨尺度系数
收缩''分析：系数范数随参数量幂律收缩（$\kappa=0.314031$），量化了配比
敏感度随规模递减的机理，结果详见表 \ref{tab:p1_domain} 与附录 B。

\textbf{针对问题二：构建含数据质量维度的广义标度律模型。}首先，在经典
标度律 $L=E+A N^{-\alpha}+B D^{-\beta}$ 上，用 1176 条 Pythia 训练轨迹
\begin{sloppypar}%
拟合得到 $E=1.689798$、$A=0.353980$、$\alpha=0.339977$、$B=1.240306$、
$\beta=0.279878$（拟合 $R^2=0.999$），与文献 Chinchilla 参数一致。随后，
跨家族验证引入
``家族偏移修正 $R^2$''处理绝对 Loss 尺度差异，基线族外验证 $R^2=0.830$；
对四种候选质量扩展形式统一拟合后，采用\textbf{质量--参数量交互形式}
$L=E+A N^{-a}+B D^{-b}+C(1-Q)^{g}N^{-h}$（$R^2=0.979073$），其物理含义
是``模型规模越大，对数据质量缺口的敏感性越低''，$Q=1$ 时自动退化回
经典形式。最后，弹性分析显示质量弹性（$-0.146080$）高于参数量
（$-0.060185$）与数据量（$-0.029942$）：质量提升 0.1 等价于增加
0.288515B 参数；同时诊断出附件 B8 的 $Q$ 列与 B6/B7 方向相反（组内
相关 $+0.98$ vs $-0.93$），说明其为半合成外推数据，仅作结构对照，
结果详见表 \ref{tab:p2_forms} 与附录 B。
\end{sloppypar}

\textbf{针对问题三：构建算力约束下的多维资源联合优化模型。}首先，以广义
标度律为目标函数，在预算 $C\in\{10^{19},10^{22},10^{24}\}$ FLOPs 下联合
优化参数量 $N$、数据量 $D$ 与质量 $Q$，其中训练成本 $C_{\text{train}}=6ND$、
质量成本 $C_{Q}=D[g(Q)-g(Q_0)]_{+}$、注意力成本
$C_{\text{attn}}=\eta N D L_{\text{ctx}}$，并解析给出注意力与训练成本
相等的临界点 $L_{\text{ctx}}^{\text{crit}}=6/\eta=30000$。随后，跨活跃集/
无导数/全局进化/罚函数精修等\textbf{九类求解框架}在 9 组预算—成本实例上
交叉验证得到全局一致最优解，三档预算下最优分配呈现清晰的结构性转移：
预算低于约 $10^{18}$ 量级时最优 $Q=Q_0$（纯规模扩张），越过阈值后质量
投入激活，$10^{22}$ 量级时 $Q$ 饱和于 1，三种质量成本函数下的转移阈值
分别为 $6.3\times10^{17}$、$2.0\times10^{18}$、$3.2\times10^{18}$。最后，
把语料配比 $p$ 提升为第三层内生决策变量：配比联合优化显示最优配比向
最高质量域（小说，$Q=0.631$）集中，但配比杠杆仅约 2\%，直接质量投资
才是主导途径；跨问题\textbf{闭环外部验证}：以 57 个真实开源训练点对照
最优轨迹 $N^{*}(C)$（对数规模相关 0.92、中位偏差 0.36 dex，72\% 落在
$\pm0.5$ dex 内），贴合度优于经典 Chinchilla 规则约 30\%，结果详见表
\ref{tab:p3_lctx} 与附录 B。

\textbf{针对问题四：构建技术演进分解与前沿预测模型。}首先，以 C1 开源模型
前沿为对象，建立 90\% 分位数回归（LP/statsmodels/sklearn/L-BFGS-B/Adam
五框架交叉复算）$\ln S=c+b_N\ln N+b_T t$（$b_N=0.364315$、$b_T=0.089045$），
把前沿能力年增速分解为规模贡献 83.7\% 与非规模技术贡献 16.3\%。随后，
利用 C4 估算开源模型参数量年均对数增速 1.251，构建基础与``算力增长
放缓''两种情景的前沿预测：未来 12 个月前沿平均分由 41.6 升至 71.7（基础）
或 57.1（放缓），24 个月升至 123.9 或 78.6，并给出 90\% 自助置信区间。
最后，C6 桥接表明 $\text{logit}(A)=0.852-3.304\ln L$；C8 逐任务聚合与
C1 排行榜对照 Spearman 相关 0.989，验证聚合口径可靠，结果详见表
\ref{tab:backtest} 与附录 B。

\textbf{灵敏度与稳健性}分析表明：质量权重组合扰动（0.4:0.6 至 0.6:0.4）
下域级质量排序稳定；广义标度律对 $Q$ 项形式选择不敏感（加性/交互/乘性
$R^2$ 差距不超过 0.008）；结构性转移阈值对三种成本函数均落在 $10^{18}$
量级；前沿分解对分位数（0.5--0.99）稳健：规模贡献占比随分位数单调上升
（64.9\%$\to$88.8\%），``规模主导''恒成立，且每分位五框架复算一致
（$b_N$ 极差 $<$0.2\%、$b_T$ 极差 $<$2\%）。全套结论经受严格检验：参数
与弹性 Bootstrap 区间（300 次重抽）、175 个参考点上的弹性排序、家族留出
与跨框架求解器收敛（24 初值、九类框架一致）、抽样规模收敛性等均在正文
给出统计依据，且四个问题的拟合/优化/预测均经 scipy/statsmodels/sklearn/
torch 独立实现交叉复算一致（如配比岭回归五框架 $\kappa=0.314031$ 极差
$3\times10^{-10}$）；留出交叉验证表明交互($N$) 形式留出最优（RMSE
0.051，相对经典降约 60\%）；联合优化相对纯规模基线在 $0.8\%$--$6.7\%$
区间持续占优；跨问题\textbf{能力杠杆总览}给出投入弹性排序：上下文
（0.197）$>$ 预算（0.161）$>$ 质量（0.146）$>$ 时间（0.089）$>$
参数（0.060）$>$ 数据（0.030），为预算分配结论提供一致性坐标。

\end{abstract}
